# 林业灵活用工核验领域约定

项目面向集体林权改革与林下产业协作场景。林下基地吸纳村民灵活务工，山区网络
不稳定，核验服务必须做到：**离线先记、补传不丢、异常留痕、裁定留证、结果可解释**。

## 核心对象

- **任务（Task）**：绑定基地、地块与班组的养护作业，名册按版本演进，
  临时换人产生新的名册版本，事件按发生时间套用对应版本。
- **事件（WorkEvent）**：开工 / 暂停 / 复工 / 完工 / 复核。事件不可变，
  携带来源（source）、发生时间（occurred_at）与到达序号（seq）；
  更正只能以新事件 `supersedes` 旧事件，旧版本保留用于追溯。
- **证据摘要（EvidenceRef）**：只保存照片等材料的摘要值与降精度位置网格，
  不保存原始照片与精确坐标；同一摘要被多条事件使用即触发冲突提示。
- **申诉（Dispute）**：任何补数都必须走“申诉 + 复核裁定”，不允许管理员直接改数。
- **结算批次（SettlementRun）**：按规则由事件流生成，结果不可变，
  重新生成产生新批次，便于发薪前对照。

## 推导与解释

- 时间线由事件按（发生时间, 到达序号）排序重放得到，离线补传、倒序到达
  结果一致；无法解释的异常（未闭合片段、完工后再开工等）不丢弃，记入
  anomalies 一并展示。
- 跨午夜作业按本地自然日（东八区）切片，申诉与结算都按日核对。
- 每条结算行携带解释链：来源事件、适用规则编码、扣减原因、冲突与申诉引用，
  可通过 `GET /settlements/{run}/lines/{line}/explain` 逐行核对。

## 结算规则（forestry-hours/v1）

- R1 有效工时 = 开工到暂停/完工的闭合区间，暂停区间不计；
- R2 跨午夜作业按本地自然日切片；
- R3 同一村民每日计酬上限 10 小时，超出记为封顶扣减；
- R4 跨任务时间重叠只计一次，后到片段的重叠部分暂扣待核；
- R5 申诉未决的片段暂缓结算，裁定后按裁定入账（认可 / 调整 / 驳回）；
- R6 未经复核的时间线不计入待结算；
- R7 复核调整按复核事件登记的调整分钟入账。

## 冲突提示

跨基地/跨任务工时重叠、同一证据摘要复用、疑似重复签名（同类记录相隔
≤10 分钟）、临时换人未登记、证据位置网格与地块网格不一致。冲突由当前有效
事件即时推导，编号确定，可回溯到具体事件。

## 隐私与权限

- 个人位置只保存约 1 公里网格（两位小数），精确坐标当场换算后丢弃；
  服务内不保存姓名、证件号，村民一律以工号引用。
- 角色：带班人 leader、基地管理员 base_admin、联盟复核员 reviewer、
  结算员 finance、隐私审计员 auditor、务工村民 worker。
  涉及个人数据的接口只向职责范围内的角色开放，村民仅可查看本人数据。
- 所有个人数据读取与治理动作（换人、裁定、生成结算）都写入审计日志，
  仅隐私审计员可查阅。
